# Power BI Sales Dashboard

This project is a **Sales Analysis Dashboard** created using Microsoft Power BI.

## 📸 Dashboard Preview

![Power BI Sales Dashboard](dashboard-preview.png)

The dashboard provides an overview of sales performance and helps analyze important business metrics such as revenue, cost, profit and profit margin.

## 📊 Dashboard Features

* Sales performance analysis
* Gross and net revenue analysis
* Total cost analysis
* Profit analysis
* Profit margin tracking
* Monthly performance analysis
* Category-based analysis
* City-based analysis
* Manager performance analysis

## 🛠 Tools Used

* Microsoft Power BI
* Power Query
* DAX
* Data visualization

## 📁 Project File

The Power BI project file is available in this repository:

`SATIS DASBOARD PROJESI.pbix`

You can download the file and open it with **Microsoft Power BI Desktop**.
